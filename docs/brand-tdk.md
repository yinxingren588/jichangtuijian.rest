## 后续修改与本轮范围

每个品牌的独立字段维护在 src/data/brand-seo.json，对应条目以 slug 区分。描述与关键词中的双花括号是事实占位符：plans取同一套餐表的价格与流量，coupon和couponCode取已录入代码，devices与protocols取设备和协议记录，billing保留年付月均的总额核对说明。更新套餐后重新构建即可同步，不要将占位符替换成重复维护的数值。网站共享模板不会再用同一规则覆盖品牌标题；套餐和图表正文保留。修改后重新构建并运行 npm run export:tdk 可导出新清单。

本轮应用范围为本地网站与交付压缩包；没有执行正式上线、域名配置或搜索引擎远端提交。正式路径表示网站配置中的品牌地址，不表示本轮已经部署。

# 品牌独立 TDK 验证 · 2026-10-24

本轮为 28 家机场与 5 家商业 VPN 编写 33 组独立 Title、Description、Keywords 和 H1。完整输出见 brand-tdk.md，机器可读输出见 brand-tdk-export.json；二者从实际构建的 HTML 导出并与独立配置核对。

## 实现与内容

- 所有品牌的 SEO 文案逐条保存在 src/data/brand-seo.json，不再依赖“品牌名加同一后缀”生成标题。
- 网页标题、页面大标题与描述分别维护，Open Graph 和 Twitter 标题、描述同步输出。关键词仅为对应品牌输出，未加到其他页面。
- 28 家机场描述保留各自两档参考价格和流量；12 个已有优惠码大小写保持，未编造其他品牌优惠码。
- 年付月均与完整年费、按月额度与一次性总额度分别表述。飞猫云、Firefly、快狸保留年付完整总额待确认；飞V保留200 GB一次性总额度；EdgeNova保留86/168元完整年费。
- 28 家机场说明现有维护者图表的核验范围；5 家 VPN 明确本站暂无测速图，价格、流量与重置周期缺失项保留。
- Canonical、品牌路径、品牌顺序、原有套餐与图表正文、推广链接、优惠码操作及前后品牌导航保留。面包屑使用简短品牌名称；手机大标题使用中文主名称，英文别名保留在相关标题、描述或关键词中。
- 品牌页面修改日期与 Sitemap 更新为2026-10-24，原有套餐参考查看及图表日期没有改成新的核验日期。

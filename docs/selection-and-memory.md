# 筛选、对比分享与本地品牌清单

更新：2026-10-23。本轮只处理用户确认的前三项功能。

## 已完成

1. 品牌资料库增加付款周期、预算上限、最低标示流量筛选，可与品牌名称及优惠码筛选组合。结果中的价格和流量必须来自同一档满足全部条件的套餐；年付总额与月付分别计算，年付月均不作实付预算。筛选后会显示真正匹配的档位名称、价格和流量。
2. 对比页实时将候选品牌及套餐、图表、全部资料视图同步到网址。可复制链接、刷新恢复、保存到本机、恢复保存或删除保存。无可用自动剪贴板时提供手动复制链接输入框。
3. 新增“我的清单”入口。品牌目录、品牌首屏和专题详细卡片均可添加或取消候选。候选最多 4 个，可直接带入对比；最近浏览最多 6 个，自动记录本站品牌详情，重复访问移至前列。支持单个移除、清空候选和清空浏览记录。

## 使用入口

- 品牌筛选：http://127.0.0.1:4321/airport/#brand-filters
- 候选与最近浏览：http://127.0.0.1:4321/airport/#my-brands
- 对比示例：http://127.0.0.1:4321/compare/?brands=yinxingren,muguang,breezenet&view=charts

记录仅保存在当前浏览器和站点地址，不跨设备同步。隐私政策已说明本地记录字段与清空方式。不新增第三方统计、账户或上传后台的浏览记录。

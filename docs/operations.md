# 内容维护与事实核验

## 品牌资料

统一维护 `src/data/airports.ts`，不在模板里复制价格。保留原始来源、字段含义和核验日期。每次更新先核实品牌身份，多个同名官网、代理注册入口或联盟页不能直接视为同一官方。`kind: vpn` 不得变成机场样本。

填写 `identityVerified` 必须有维护者保存的身份依据。只有 `official-data` 或 `tested` 的资料可参与对应排序；`tested` 必须同时保存 `docs/evidence/slug.json`。默认没有任何实测字段，AI/流媒体支持与地区缺失项显示尚未核实。套餐倍率只描述额度换算，不表示该服务存在某种线路；当前 VPN 基础倍率 1，未知流量不参与成本计算。

资料透明度榜仅统计四类资料是否完整，不冒充服务质量分。性价比和低预算按同币种月付比较；稳定性只比较同 cohort、至少 7 天、100 次请求且有原始记录的测试，按失败率升序，不能把不同运营商或方法设成同一 cohort。并列指标共享名次。排名组件已连接统一数据源；当前无样本。

四个机场榜单目前始终 noindex，Sitemap 中显式排除。录入数据后先审核结果，再同时修改页面 robots 条件、Sitemap filter 和 audit-seo 的预期规则，避免无资料页面抢索引。不要只取消 noindex 而不补齐内容。

## 文章与评测

文章从 `src/content/articles/` 读取，正文第一段直接回答意图，来源放 frontmatter。`draft: true` 不生成路由。标签用于自动关联相关文章。真实首次发表及修改日期分别记录；不要因每天构建而修改日期。未来独立评测使用 `docs/review-template.md`，证据文件缺失时构建拒绝发布。

新增评测后还要在评测中心添加可见索引，加入搜索及相关文章；内链脚本会发现没有入口的新页面。评测原始日志不得包含账号、订阅链接和私人信息。

## 日期和 Sitemap

本期 2026-10-23 是真实创建日期，当前非文章页面均使用该日期。后续更新请在 `src/data/page-dates.json` 登记页面路径和真实修改日期；文章从 frontmatter 的 updated 自动读取。Sitemap 生成器读取这两处日期，不使用当前系统时间。没有日期的新增页面必须先登记，不能用虚假日期补齐。

## 审计与性能

依次执行 check、build、test。验收脚本检查结构、可索引集合、内链和证据元数据，不能自动证明全部事实真实或不存在语义重复。发布前人工复核品牌身份、价格、来源与 AI 辅助正文。Lighthouse 需在真实浏览器环境运行并保存报告，当前没有评分。

本站没有追踪脚本和自建 Cookie；托管层日志和外部服务应按实际配置更新隐私政策。现有 28 条推广链接均保留维护者提供的域名、hash 路径和推荐 code，并使用 rel="sponsored noopener noreferrer"。新增代码不能默认构造券后价格。

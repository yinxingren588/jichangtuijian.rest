# 曜黑科技 · 全站改版 · 2026-10-23

用户选择风格预览 01「曜黑科技」，本轮将这一视觉方向应用至整个 Astro 网站。

## 最终实现

- 首页沿用选定预览的大标题、深蓝黑底色、冷蓝轨道示意图、浅色主按钮与三品牌套餐资料。
- 首页补充全部 28 家品牌索引、文章导读和编辑方法入口，所有数量由现有内容与数据计算。
- 全站导航压缩为一层。品牌目录、品牌详情、套餐表、文章列表、教程分组、正文、比较、搜索、百科与政策页均采用同一套深色配色和无衬线字体。
- 品牌目录保留搜索与优惠码筛选；详情页保留套餐表和优惠侧栏。优惠区域统一代码样式、复制反馈与推广披露。
- 手机菜单支持展开及 Escape 关闭；优化换行标题的完整点击区域。套餐和比较表格在自身容器中横向滑动。
- 使用内联 SVG 展示抽象轨道，不表示真实线路或测量结果。没有新增外部字体或图片请求；减少动态效果偏好下关闭过渡。
- 底层继续使用 Astro 静态生成，保持原有 URL、来源、价格口径、推广链接、优惠码大小写和内容数量。

## 故障中心写了什么

中心地址：/troubleshooting/。六条路径每条五步，共30个不同检查；每一步都包含操作、观察结果和下一步判断。每条路径另有结束判据、恢复临时改动的方法、反馈说明及可复制的脱敏提纲。

1. 订阅更新失败或节点未变化：区分下载、解析和连接，核对账户与格式，有限重试后验证一个任务。
2. 显示已连接但网页打不开：基础网络、应用路径、错误环节与单节点对照分别检查。
3. 测速快但视频卡：固定画质与任务，检查本地竞争、有限节点对照、速度单位和持续播放。
4. 仅平台或AI功能失败：页面、登录、具体功能与账号资格分别记录，旧图与现状按日期核对。
5. 流量掉得快或余额不同：对齐时间窗口、单位、统计范围，核对重置/到期、倍率与共享设备。
6. 切换网络或睡眠唤醒后断线：接入网络、客户端重连、新旧任务和恢复流程分别验证。

提供症状关键词筛选、无匹配提示、清除筛选、展开/收起、六个稳定锚点及复制提纲。锚点会展开对应路径；关闭脚本时正文仍完整写入HTML，读者可以手动展开和复制。正文沿已有文章、系统教程及支持工单指南继续阅读，避免再创建六篇重复通用教程。

故障中心没有收集日志或上传资料的表单，不保存筛选词或写入本地存储。复制只在点击时写入预设提纲，不读取剪贴板。隐私政策已同步说明。操作建议为通用排查，未声称已在每种客户端版本或读者真实设备执行，也不把假设原因当作已确定故障。
